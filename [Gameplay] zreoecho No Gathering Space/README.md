# 取消采集空地需求

仅对人类玩家生效：移除伐木场、炭窑、狩猎小屋、果园等采集建筑的周边空地需求。建筑占地、道路、劳动力等其他条件仍需满足。

## 安装

1. 退出《纪元 1800》
2. 将本文件夹复制到游戏的 `mods` 目录（推荐配合 [Anno Mod Loader](https://github.com/anno-mods/Anno1800ModLoader)）
3. 启动游戏并启用本模组
4. 请勿同时保留同一 Mod 的 ZIP 和解压目录
