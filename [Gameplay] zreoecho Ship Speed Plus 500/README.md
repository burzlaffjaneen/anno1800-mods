# 玩家海船加速 +500%

仅对人类玩家生效：指定海船基础航速增加 500%（无其他修正时为基础速度的 6 倍）。飞艇不包含在内。进入地区时会重新应用。

## 安装

1. 退出《纪元 1800》
2. 将本文件夹复制到游戏的 `mods` 目录（推荐配合 Anno Mod Loader）
3. 启动游戏并启用本模组
4. 请勿同时保留同一 Mod 的 ZIP 和解压目录
