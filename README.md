## 安装

1. 退出游戏
2. 将需要的模组**文件夹**复制到《纪元 1800》的 `mods` 目录  
   （推荐使用 [Anno Mod Loader](https://github.com/anno-mods/Anno1800ModLoader)）
3. 启动游戏并在模组列表中启用
4. **不要**同时保留同一模组的 ZIP 和解压目录

也可从 [Releases](https://github.com/burzlaffjaneen/anno1800-mods/releases) 下载各模组的单独 ZIP。

## 皇冠岛已知问题

双人 + 普通港口开局时，可能出现「只能看见对方岛屿」的视野问题。请改用「船只开局」，自行前往皇冠岛建造贸易站。单人选角落、双人选雪花，双方同版本并新开档。

## English (short)

Four Anno 1800 mods: no gathering-space requirement, +500% sea-ship speed, four player-only boosts, and experimental rich Crown islands. Install each folder into your `mods` directory (Mod Loader recommended). Crown islands 0.1.4: in 2-player mode with a normal port start, each player may only see the other's island — use ship start instead. Unofficial; Anno 1800 © Ubisoft.
