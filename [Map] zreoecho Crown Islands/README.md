# 皇冠富饶岛（测试版 0.1.4）

为单人或双人开局提供皇冠岛，保留七种肥力及 58 个资源槽。需要 **沉没的宝藏** DLC。

## 用法

- **单人**：选择「角落」地图模板
- **双人**：选择「雪花」地图模板；双方必须使用相同版本并 **新开档**
- **双人开局建议**：选择「船只开局」。开局船只会出现在皇冠岛附近，各自驾驶前往自己的皇冠岛并自行建造贸易站

## 已知问题

双人模式下若选择普通港口开局，每位玩家可能只能看见对方的岛屿（视野初始化问题）。尚未修复，请改用「船只开局」。

## 安装

1. 退出《纪元 1800》
2. 将本文件夹复制到游戏的 `mods` 目录（推荐配合 Anno Mod Loader）
3. 启动游戏并启用本模组
4. 请勿同时保留同一 Mod 的 ZIP 和解压目录
