# 仅玩家四项增强

仅对人类玩家生效：

- 生产建筑生产力 +300%
- 住宅容量 +100%
- 公共服务距离 +100%
- 发电厂供电范围扩大，并增强电力生产加成（发电厂须运行且通过道路连接用电建筑）

## 安装

1. 退出《纪元 1800》
2. 将本文件夹复制到游戏的 `mods` 目录（推荐配合 Anno Mod Loader）
3. 启动游戏并启用本模组
4. 请勿同时保留同一 Mod 的 ZIP 和解压目录
